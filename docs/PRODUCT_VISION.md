# Visión

AlineaApp será una herramienta de finanzas personales en español, inicialmente para una persona autorizada, preparada para múltiples usuarios y registro público posterior. La claridad de saldos y compromisos precede a automatizaciones e IA.

Fase 00 entrega exclusivamente una plataforma local verificable: UI conectada, API, PostgreSQL, migraciones, infraestructura, pruebas y documentación. No representa actividad financiera ni habilita acceso de usuarios.

La siguiente fase introduce registro restringido y autenticación por teléfono verificado mediante OTP SMS. Los datos del piloto se configurarán fuera del repositorio cuando corresponda.
