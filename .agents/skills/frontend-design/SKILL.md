Lee [diseño](../../../docs/DESIGN_SYSTEM.md) y [visión](../../../docs/PRODUCT_VISION.md).

- [ ] UI española, mobile-first; comprobar 320px y escritorio, teclado y focus visible.
- [ ] Mostrar datos de endpoints reales, nunca balances ficticios ni usuario provisional.
- [ ] Cubrir carga, error, vacío, dependencia pendiente y reintento sin depender solo del color.
- [ ] Respetar tokens, contraste y targets de 44px. Evitar tarjetas decorativas, degradados e iconos innecesarios.
- [ ] Verificar con navegador cuando esté disponible y registrar lo observado, no solo el build.

La identidad visual sigue provisional; no añadir dependencias de diseño por conveniencia.
